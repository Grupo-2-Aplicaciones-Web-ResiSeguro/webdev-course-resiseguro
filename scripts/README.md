# Lección 2: Estructura básica de HTML

## Descripción
En esta lección aprenderás la anatomía de una página web: sus etiquetas, metadatos y jerarquía de títulos.  
Corresponde a la segunda parte del curso “Fundamentos de Desarrollo Web” desarrollado por el equipo **ResiSeguro** (UPC – curso 1ASI0730 Aplicaciones Web, NRC 7426).

## Objetivo
Comprender la estructura interna de un documento HTML y organizar correctamente los contenidos utilizando las etiquetas `<head>`, `<body>`, `<meta>`, `<h1>`–`<h6>`.

## Archivos incluidos
- **/starter-files/** → Contiene el código inicial de la práctica (estructura básica vacía).  
- **/completed-examples/** → Contiene el resultado final con títulos, párrafos y listas.  
- **/scripts/** → Carpeta reservada para archivos adicionales (no aplica en esta lección).
